## 🎯 Summary
- 기능명: [R-002] 조건 완화 미리보기(REQ-FUNC-013) + 전부 불충족 분기 시뮬레이션(REQ-FUNC-015) + 재탐색 필터 변환(REQ-FUNC-016)
- Read/Write 구분: **Query**(전부 순수 계산/변환, DB 쓰기 없음 — 확정 전까지 아무것도 저장하지 않음). 제안/응답의 실제 확정(Command)은 R-003으로 분리.
- 목적: 실제 미달량 기준의 완화 시뮬레이션을 즉시(경로 API 재호출 없이) 미리보기하고, 완화로도 후보가 0개면 전부 불충족 분기를 시뮬레이션하며, 그마저 회복 불가할 때 네이버 검색 필터로 조건을 변환해 제안한다. 세 기능은 원 SRS §4.1.3(완화·재탐색 분기 플로차트)에서 하나의 순차 파이프라인으로 서술된 동일 흐름이다.
- 병합 근거(`TASK-개수-축약-분석.md` #5): R-002(완화 미리보기)·R-004(전부 불충족 시뮬레이션)·R-005(재탐색 필터 변환)는 원 SRS §4.1.3 결정 트리 안에서 순서대로 이어지는 한 흐름이며, R-004는 R-002의 계산 로직을 그대로 재사용하고 R-005는 R-004의 회복 실패 결과를 입력으로 받는 연쇄 관계였다. 세 기능 모두 개별로는 Low~Medium 복잡도이고 DB 쓰기가 전혀 없는 순수 계산이라는 공통점도 있다.
