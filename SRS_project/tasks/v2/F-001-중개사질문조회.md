## 🎯 Summary
- 기능명: [F-001] 중개사 질문 카드 — 조회(REQ-FUNC-022) + 답변 기록(REQ-FUNC-022)
- Read/Write 구분: **Query+Command** — 조회(확인 필요 항목을 질문 목록으로 변환)와 답변 기록(DB 쓰기, 보류 상태 갱신)을 한 파일에 두되, 함수는 명확히 분리된 두 모듈로 구현한다(`field-record.queries.ts` vs `field-record.actions.ts`).
- 목적: 확인 필요 항목을 방문 전 중개사 질문 목록으로 조회하고, 답변 기록 시 보류 상태를 갱신한다.
- 병합 근거(`TASK-개수-축약-분석.md` #7): 같은 `BrokerQuestion` 엔티티에 대한 조회/기록이며, 원 SRS에서도 REQ-FUNC-022 하나로 서술됐고 애초부터 테스트 companion(TEST-F-BROKER)을 공유하고 있었다. CQRS 분리 원칙은 함수/파일 단위로는 그대로 유지한다.
