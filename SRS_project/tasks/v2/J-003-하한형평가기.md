## 🎯 Summary
- 기능명: [J-003] 확장 조건 평가기 3종 — LowerBoundEvaluator(전용면적), PresenceEvaluator(주차), ExactMatchEvaluator(매물유형) — REQ-FUNC-010B
- Read/Write 구분: **Query**(순수 계산, DB 쓰기는 J-001의 저장 함수 재사용)
- 목적: J-001(상한형)에 이어 나머지 세 조건 타입을 순차로 추가한다. 개인 구현 난이도 지시(TASK-A2)에 따라 하한형→유무형→일치형 순서를 그대로 지키되, 세 평가기를 하나의 Task로 묶는다. 완료 시 4개 조건 유형(상한·하한·유무·일치) 전체가 구현된다.
- 병합 근거(`TASK-개수-축약-분석.md` #2): 세 평가기 모두 `domain/judgment/evaluators/`의 같은 파일 패턴, 같은 `ConditionTypeRegistry`에 순차 등록하는 구조이며, TEST-J-EXT가 이미 셋을 하나로 검증하고 있었다. 개별로는 각각 L(낮음) 복잡도.
