## 🧪 Acceptance Criteria (BDD/GWT)
> 이 태스크는 원 SRS 기능 요구사항(FR)에 직접 대응하지 않는 인프라 태스크라 원본 AC가 없다.

Scenario 1: Git Push 자동 배포
- Given: main 브랜치에 커밋이 push된 상태
- When: Vercel이 이를 감지함
- Then: 별도 CI/CD 설정 없이 빌드·배포가 자동으로 완료된다(REQ-NF-008, C-TEC-007).

Scenario 2: 마이그레이션 자동 반영
- Given: 새 Prisma 마이그레이션이 포함된 커밋이 배포됨
- When: 빌드가 실행됨
- Then: `prisma migrate deploy`가 배포 환경 스키마를 최신 마이그레이션으로 맞춘다(REQ-NF-010).
