## 🧪 Acceptance Criteria (BDD/GWT)
Scenario 1: 초대 발급 (원 SRS AC-05-01)
- Given: A가 관계 유형을 선택한 상태
- When: 공유를 실행함
- Then: 초대 링크와 보조 코드를 발급하고 B 참여 전까지 대기 상태를 표시한다(초대 수단 2종 발급률 100%).

Scenario 2: 재질문 없음 (원 SRS AC-05-02)
- Given: A가 이미 초대를 생성한 상태
- When: B가 참여함
- Then: B에게 같은 관계 유형을 다시 입력하도록 요구하지 않는다(재질문 0건).

Scenario 3: B 맥락 우선 노출 (원 SRS AC-06-01)
- Given: B가 유효한 링크·코드를 받은 상태
- When: 참여를 시도함
- Then: B의 조건 입력 화면보다 먼저 후보 최대 5개와 A 선호 카드를 표시한다(초대 클릭 → B 첫 화면 응답 30초 이내, P95, REQ-NF-001).

Scenario 4: 무효 초대 처리 (원 SRS AC-06-02, 실패)
- Given: 초대 링크·코드가 만료·존재하지 않는 상태
- When: B가 참여를 시도함
- Then: 후보·선호 카드를 노출하지 않고 만료·오류 상태를 표시한다(무효 초대로 후보 노출 0건).
