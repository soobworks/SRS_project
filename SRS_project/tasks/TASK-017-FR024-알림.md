## 🧪 Acceptance Criteria (BDD/GWT)
Scenario 1: 트리거 대비 발송률 100% (원 SRS AC-24-01)
- Given: 한 사용자가 조건을 입력·변경하거나 완화를 제안한 상태
- When: 해당 이벤트가 발생함
- Then: 다른 사용자에게 상태 변화를 알린다(트리거 발생 대비 알림 발송률 100%).

Scenario 2: 후보 변경 알림 누락 없음 (원 SRS AC-24-02, 예외)
- Given: 후보가 추가·교체·소진되거나 방문 후보 선택 상태가 바뀐 상태
- When: 해당 이벤트가 발생함
- Then: 상대에게 무엇이 변경되었는지 알린다(알림 누락 0건).
